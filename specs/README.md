# Specs

Una spec por cambio de comportamiento. El formato está en `../CAMBIOS.md`.

```
backlog/   lo que todavía no se ejecuta
active/    lo que se está haciendo AHORA (idealmente una sola)
done/      terminadas y verificadas — el historial de por qué las cosas son así
```

**La regla:** nada se mueve a `done/` sin que su criterio de éxito haya corrido
y pasado. "Lo probé y anduvo" no alcanza — el 22/07 eso llevó a declarar dos
veces algo arreglado que no lo estaba (`../memory/learning.md` #1).

Numeración correlativa: `001-nombre-corto.md`.
